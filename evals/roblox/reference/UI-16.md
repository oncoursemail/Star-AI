Use **Scale** for sizes and positions that should follow the screen and **Offset** for fixed pixel amounts such as borders [1]. A UDim2 holds both, so a frame can be half the screen wide plus 10 pixels. To keep an icon square on any screen shape, add a UIAspectRatioConstraint with AspectRatio 1 [2].
