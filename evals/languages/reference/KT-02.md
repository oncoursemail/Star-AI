`target` is a mutable class property (`var`), so between the `!= null` check and the call another thread or a custom
getter could have changed it. The compiler therefore cannot smart cast it to non-null `Player`.

Idiomatic fixes: read it once into a local `val`, or use a safe call:

```kotlin
val t = target
if (t != null) t.attack()

// or
target?.attack()
// or, for several statements
target?.let { it.attack(); it.taunt() }
```
