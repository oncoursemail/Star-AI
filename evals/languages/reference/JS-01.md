`Array.prototype.forEach` ignores the return value of its callback. Your callback is `async`, so it returns a promise, and `forEach` throws that promise away: forEach does not wait for any of them. The loop finishes immediately, `console.log("all saved")` runs before any save completes, and because nobody awaits or catches the promises, a failing `save` becomes an unhandled rejection. Node's default `--unhandled-rejections=throw` mode then crashes the process.

Fix it with one of these:

```js
// parallel: all saves at once, wait for all of them
await Promise.all(ids.map(id => save(id)));
console.log("all saved");

// sequential: one at a time
for (const id of ids) {
  await save(id);
}
console.log("all saved");
```

Use `Promise.allSettled` to keep going when some saves fail. Wrap the call in `try`/`catch` (inside an `async` function, or use top-level `await` in an ES module) so errors are handled. The typescript-eslint rules `no-floating-promises` and `no-misused-promises` catch this pattern.
