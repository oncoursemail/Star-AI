Haskell is lazy: `foldl` does not add the numbers as it goes. It builds a huge chain of unevaluated thunks (`((0 + x1) + x2) + ...`) for both the sum and the count, and only evaluates them at the end, so memory grows with the list and evaluation can overflow the stack.

Switching to `foldl'` (from `Data.List`) is necessary but not enough here: `foldl'` only evaluates the accumulator to weak head normal form (WHNF), which for a tuple means the pair constructor, not its components. Force the components with bang patterns (or `seq`, or a data type with strict fields):

```haskell
{-# LANGUAGE BangPatterns #-}
import Data.List (foldl')

mean :: [Double] -> Double
mean xs = s / fromIntegral n
  where
    (s, n) = foldl' step (0, 0 :: Int) xs
    step (!a, !c) x = (a + x, c + 1)
```

Now each step adds immediately and the function runs in constant memory.
