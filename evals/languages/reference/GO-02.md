An interface value in Go is a pair: a dynamic **type** and a **value**. It is `nil` only when both are nil. Returning
`verr` (a nil `*ValidationError`) as `error` produces an interface whose type is `*ValidationError` and whose value is
nil: a **typed nil**, which is not equal to `nil`, so `err != nil` is true.

Fix: return a literal `nil` when there is no error, and only return the concrete pointer when it is set.

```go
func validate(p Player) error {
    if p.Name == "" {
        return &ValidationError{Field: "name"}
    }
    return nil
}
```
