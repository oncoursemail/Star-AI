`time.sleep(1)` is a blocking call. asyncio runs every coroutine on one thread with a single event loop, and a coroutine only gives control back to the loop at an `await`. `poll` never awaits, so each call blocks the event loop for a full second and the five calls run one after another: 5 seconds in total. `gather` cannot overlap work that never yields.

Fix: use the non-blocking `await asyncio.sleep(1)`. Wrap genuinely blocking functions (for example a `requests` call) in `await asyncio.to_thread(fn, ...)`. For structured concurrency, use `asyncio.TaskGroup` (3.11+). It waits for all children and cancels the siblings if one fails.

```python
import asyncio

async def poll(i: int) -> int:
    await asyncio.sleep(1)
    return i

async def main() -> None:
    async with asyncio.timeout(5):
        async with asyncio.TaskGroup() as tg:
            tasks = [tg.create_task(poll(i)) for i in range(5)]
    print([t.result() for t in tasks])   # about 1 second in total

asyncio.run(main())
```

A failure inside the group surfaces as an `ExceptionGroup`. Handle it with `except*`.
