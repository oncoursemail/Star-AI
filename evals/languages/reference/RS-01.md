This is error **E0502**: cannot borrow `scores` as mutable because it is also borrowed as immutable. `first` is a shared
(immutable) borrow of the vector, `scores.push(40)` needs a mutable borrow, and `first` is still used later in
`println!`. The rule exists for a real reason: `push` may reallocate the buffer, which would leave `first` pointing to
freed memory.

Fix: copy the value out (an `i32` is `Copy`), or finish using the reference before pushing.

```rust
fn main() {
    let mut scores = vec![10, 20, 30];
    let first = scores[0]; // copy, no borrow kept
    scores.push(40);
    println!("first = {first}");
}
```
