The problem is that `Hash.new([])` uses one single default array for every missing key. `groups[p.team]` returns that shared default object, and `<<` mutates it, but nothing is ever assigned back, so the key is never stored in the hash. That is why `p groups` shows `{}` and every lookup returns the same array with all the names.

Fix: use the block form `Hash.new { |h, k| h[k] = [] }`, which creates a new array per key and stores it:

```ruby
groups = Hash.new { |h, k| h[k] = [] }
players.each { |p| groups[p.team] << p.name }
```

Even simpler: `players.group_by(&:team).transform_values { |ps| ps.map(&:name) }`.
