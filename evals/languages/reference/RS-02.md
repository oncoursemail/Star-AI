This is **E0373**. `thread::spawn` requires a `'static` closure because the new thread could outlive `main`'s stack
frame, but the closure borrows `names`.

Fix 1: a `move` closure transfers ownership of `names` into the thread:

```rust
let h = std::thread::spawn(move || println!("{}", names.len()));
h.join().unwrap();
```

Fix 2 (keep using `names` afterwards): `std::thread::scope` guarantees the threads finish before the scope ends, so
they may borrow locals:

```rust
std::thread::scope(|s| {
    s.spawn(|| println!("{}", names.len()));
});
println!("still mine: {names:?}");
```

If several threads need shared ownership beyond a scope, use `Arc<Vec<String>>` and clone the `Arc`.
