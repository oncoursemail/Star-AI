`realloc` returns `NULL` when it cannot grow the block, and in that case the original block is **not** freed: it is
still valid and still owned by you. Your code writes that `NULL` straight into `*items`, so the only pointer to the old
block is lost (a memory leak), and the next line `(*items)[*len] = value` dereferences a null pointer (undefined
behaviour, usually a crash).

Fix: put the result in a temporary pointer, check it, and only then replace the original. Also check the size
multiplication for overflow.

```c
#include <stdckdint.h>
#include <stdlib.h>
#include <errno.h>

int push(int **items, size_t *len, int value) {
    size_t bytes;
    if (ckd_mul(&bytes, *len + 1, sizeof **items)) return EOVERFLOW;
    int *tmp = realloc(*items, bytes);
    if (tmp == NULL) return ENOMEM;   /* *items is untouched and still owned by the caller */
    *items = tmp;
    (*items)[*len] = value;
    (*len)++;
    return 0;
}
```
