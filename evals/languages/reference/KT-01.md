Coroutine cancellation is cooperative: when `viewModelScope` is cancelled, the suspended `delay` throws
`CancellationException`. Your `catch (e: Exception)` catches it (it is an `Exception`), logs it and loops again, so the
coroutine swallows its own cancellation and never stops.

Fix: rethrow `CancellationException` (or catch only the specific exceptions `poll()` throws), and loop on `isActive`:

```kotlin
viewModelScope.launch {
    while (isActive) {
        try {
            poll()
        } catch (e: CancellationException) {
            throw e
        } catch (e: IOException) {
            log(e)
        }
        delay(5_000)
    }
}
```
