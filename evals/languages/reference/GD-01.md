Godot 4 renamed or removed several Godot 3 APIs used here:

- `KinematicBody2D` is now `CharacterBody2D`.
- `export` became the `@export` annotation.
- `move_and_slide()` now takes no arguments. It uses the body's built-in `velocity` property, and the floor direction is the `up_direction` property (default `Vector2.UP`). Set `velocity`, then call `move_and_slide()`.
- `PackedScene.instance()` is now `instantiate()`.
- `yield(obj, "signal")` was removed. Use `await` on the signal: `await get_tree().create_timer(0.5).timeout`.

```gdscript
extends CharacterBody2D

@export var speed: float = 200.0
var bullet: PackedScene = preload("res://bullet.tscn")

func _physics_process(_delta: float) -> void:
    velocity = Vector2(Input.get_axis("left", "right") * speed, velocity.y)
    move_and_slide()

func shoot() -> void:
    var b := bullet.instantiate()
    add_child(b)
    await get_tree().create_timer(0.5).timeout
```
