In the **2024 edition** `gen` is a **reserved keyword** (for future generator blocks), so `rng.gen()` no longer parses
as a method call. Two fixes:

- Use the raw identifier syntax: `let roll: u32 = rng.r#gen();`
- Better: upgrade to rand 0.9, which renamed the method to `random()`:

```rust
use rand::Rng;
let mut rng = rand::rng();
let roll: u32 = rng.random();
let die = rng.random_range(1..=6);
```

`cargo fix --edition` applies the `r#gen` rewrite automatically when migrating.
