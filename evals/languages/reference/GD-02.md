`body_entered` is emitted while the physics server is flushing its queries (inside the physics step). Godot forbids changing collision state, such as enabling or disabling a shape or adding physics nodes, at that moment, because it would modify the very data being iterated.

Defer the changes so they run after the physics step, at the end of the frame (idle time):

- `set_deferred("disabled", true)` on the CollisionShape2D.
- `add_child.call_deferred(particles)` (or `call_deferred("add_child", particles)`).
- `queue_free()` is already deferred and safe.

```gdscript
func _on_body_entered(body: Node2D) -> void:
    $CollisionShape2D.set_deferred("disabled", true)
    var fx := pickup_fx.instantiate()
    fx.global_position = global_position
    get_parent().add_child.call_deferred(fx)
    queue_free()
```
