A Server RPC only goes through when the calling client owns the actor. Ownership follows the owner chain up to a PlayerController; a door placed in the level has no owning connection, so the client's `ServerOpen()` call is dropped (the log shows a warning about no owning connection).

Fix: send the RPC through something the client owns. Add `UFUNCTION(Server, Reliable) void ServerInteract(AActor* Target);` on the player's character or PlayerController, call that on E, and in `ServerInteract_Implementation` have the server validate the request (distance to the door, door state) before calling `Door->Open()`. Make the door replicate (`bReplicates = true`) and replicate its open state with a RepNotify so clients see it. Alternatively the server can `SetOwner` an actor to the player, which suits items, not shared doors. Not compiled or run here; test with PIE in Play As Client.
