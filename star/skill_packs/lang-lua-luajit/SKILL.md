# Lua 5.4/5.5 and LuaJIT (not Luau)
- Ask or detect the runtime first. PUC Lua 5.5.1 is current; 5.4.9 is the final 5.4. LuaJIT 2.1 is a rolling release with Lua 5.1 semantics. LÖVE, Defold, Neovim and OpenResty use LuaJIT, and Defold HTML5 uses Lua 5.1, so write Lua 5.1 code for Defold.
- Luau-only syntax is a syntax error in every Lua. Remove type annotations. Replace `continue` with `goto continue` and a `::continue::` label before the loop's `end` (5.2+ and LuaJIT). Write `x = x + 1`, not `+=`. Use `("hp=%d"):format(hp)` instead of backtick interpolation. Use `c and a or b` instead of `if c then a else b` (wrong when `a` is false or nil). Use `pairs(t)`/`ipairs(t)`, not `for k, v in t`.
- No Roblox globals exist: no `game`, `task`, `Instance`, `Vector3`, `typeof`, `table.find`, `table.clear`, `table.create`, `table.freeze` or `string.split`. Split with `for part in s:gmatch("[^,]+")`.
- Numbers: 5.3+ has integer and float subtypes. `/` always returns a float (`4/2 == 2.0`). `//` is floor division and gives an integer when both operands are integers. Integers wrap on overflow. `math.type`, `math.tointeger`. `("%d"):format(2.5)` errors with "number has no integer representation". LuaJIT and Luau numbers are doubles, and LuaJIT has no `//`.
- Bitwise: 5.3+ uses `& | ~ << >>` and unary `~`. LuaJIT uses `local bit = require("bit")` and `bit.band(a, b)`, which work on 32-bit signed values. Luau uses `bit32`.
- 5.4: `local x <const> = 1` is a compile-time constant. `local h <close> = obj` calls `getmetatable(obj).__close` when the block exits, even on error. Also new: generational GC, `warn()`, `coroutine.close`.
- 5.5: `global` is a reserved word. A `global x` or `global<const> *` declaration makes undeclared free names compile errors in that scope. Varargs can be named (`function f(...args)`). For-loop control variables are read-only, so write `local i = i` to modify a copy. A nil error object becomes a string message. GC parameters use `collectgarbage("param", ...)`.
- Environments: 5.2+ uses the `_ENV` upvalue and has no `setfenv`/`getfenv`. LuaJIT and 5.1 use `setfenv`. Sandbox with `load(src, "name", "t", env)`. Mode "t" refuses bytecode, which can crash the VM.
- `#t` is only reliable on a sequence with no nil holes. Count varargs with `select("#", ...)` or `table.pack(...).n`. In 5.1 and LuaJIT, `unpack` is a global; in 5.2+ use `table.unpack`.
- Comparison never coerces types (`1 < "2"` errors), and `..` errors on nil, booleans and tables, so call `tostring()`. Lua patterns are not regex: there is no `|` and no `{m,n}`, magic characters are escaped with `%`, and `s:find(x, 1, true)` does a plain search.
- Classes: `Class.__index = Class` and `setmetatable(obj, Class)`. Metamethods belong on the metatable. `__eq` only runs when both operands are tables (or both userdata). LuaJIT ignores `__len` on tables.
- Coroutines are the only concurrency. The host owns the loop (`love.update(dt)`, Defold `update(self, dt)`). Build `wait()` with a scheduler that resumes coroutines from the frame callback. Check `coroutine.resume`'s first return value, because errors inside a coroutine do not propagate. Lua 5.1 cannot yield across `pcall`; LuaJIT and 5.2+ can.
- LuaJIT FFI: `ffi.cdef`, then `ffi.new("vec2[?]", n)` (0-based and unchecked: out of bounds corrupts memory) and `ffi.metatype` for methods. Keep a Lua reference to any buffer passed to C. Never expose `ffi` to untrusted code.
- Speed: hoist globals into locals in hot code. Build strings with `table.concat`, not with `..` in a loop. Reuse tables. In LuaJIT, keep hot loops type-stable, prefer FFI structs for bulk data, and use `luajit -jv` to see trace aborts.
- Security: never pass `os`, `io`, `debug`, `package`, `require`, `load`, `loadstring`, `dofile`, `string.dump` or `ffi` into a sandbox environment. Cap input length before using `string.rep` or patterns. Never concatenate user text into `os.execute` or `io.popen`.
- Tooling: LuaRocks (`luarocks install busted`), busted or luaunit for tests, luacov for coverage, LuaLS with `.luarc.json` `runtime.version`, luacheck or selene (std lua54/luajit), StyLua with `syntax = "Lua54"` or `"LuaJIT"`.
