# Official sources for eng-debugging strict Luau types
Checked 2026-10-13; these links support syntax and stated API argument types. They do not certify that illustrative wrong examples were executed.

- S1 — Roblox Creator Hub, Luau type checking: https://create.roblox.com/docs/luau/type-checking (strict mode, built-in Roblox instance types, type aliases, optional values and casts).
- S2 — Luau official syntax: https://luau.org/syntax/ (type aliases, exported aliases, typeof in type position, function types, parameter/return annotations).
- S3 — Roblox Creator Hub, Model class: https://create.roblox.com/docs/reference/engine/classes/Model (NPCs as Models, not a built-in NPC class).
- S4 — Roblox Creator Hub, Player class: https://create.roblox.com/docs/reference/engine/classes/Player (CharacterAdded(character:Model)).
- S5 — Roblox Creator Hub, Humanoid class: https://create.roblox.com/docs/reference/engine/classes/Humanoid (HealthChanged(health:number), Died()).
- S6 — Roblox Creator Hub, BasePart class: https://create.roblox.com/docs/reference/engine/classes/BasePart (Touched(otherPart:BasePart)).
