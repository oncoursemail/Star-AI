# Sources for engine-cocos-creator

Official documentation reviewed 2026-10-13 (accessed by web, not by a live engine run):

- https://github.com/cocos/cocos-engine/releases (3.8.8 latest stable, 3.8.7, 3.8.6)
- https://github.com/cocos/cocos4 (COCOS 4 engine, v4.0.0, MIT)
- https://docs.cocos.com/creator/manual/en/scripting/life-cycle-callbacks.html (component lifecycle order)
- https://docs.cocos.com/creator/manual/en/scripting/decorator.html (ccclass, property and class decorators)
- https://docs.cocos.com/creator/manual/en/asset/dynamic-load-resources.html (resources.load rules, spriteFrame sub-path)
- https://docs.cocos.com/creator/manual/en/asset/bundle.html (Asset Bundles, mini-game subpackage rules)
- https://docs.cocos.com/creator/manual/en/physics-2d/physics-2d-contact-callback.html (Contact2DType callbacks)
- https://docs.cocos.com/creator/3.8/manual/en/physics-2d/physics-2d-rigid-body.html (RigidBody2D, enabledContactListener)
- https://docs.cocos.com/creator/manual/en/engine/event/event-input.html (input.on, systemEvent deprecated since 3.4)
- https://docs.cocos.com/creator/manual/en/release-notes/upgrade-guide-v3.0.html (2.x to 3.x renames)
- https://docs.cocos.com/creator/manual/en/tween/tween-example.html (tween API)

These are documentation references; no editor/compiler run is claimed for the skeleton.
