# JavaScript and TypeScript
- Versions (checked 2026-10-13): ES2026 approved June 2026; Temporal and `using` are ES2027 (check engine support before use). TypeScript 7.0 (Go-native, about 10x faster, still `tsc` in the `typescript` package) went GA on 2026-07-08; 6.0 was the last JS-based compiler. Node 24 is LTS, Node 26 is Current (LTS from late October 2026). Deno 2.7, Bun 1.3.
- 0-based arrays; `arr.at(-1)` for the last item. `undefined` and `null` both mean absent (`x == null` matches both; use `??`, not `||`, to keep 0 and ""). Falsy: undefined, null, false, 0, NaN, "", 0n. Always `===`.
- Use `const` by default, `let` when reassigned, never `var`. Use Map/Set for dynamic keys. `arr.sort()` sorts as strings and mutates; use `toSorted((a, b) => a - b)`. Use `structuredClone` for deep copies; spread is shallow.
- `this` depends on the call site; a method passed as a callback loses it. Use arrow functions or `.bind`. Use `#private` class fields.
- Async: one thread, run to completion; microtasks (promise callbacks) run before timers. Always await or return promises (floating promises lose errors; Node exits on unhandled rejection). `forEach` ignores async callbacks: use `for...of` with await (sequential) or `Promise.all(map)` (parallel), `allSettled` for partial failure. Cancel with AbortController or `AbortSignal.timeout(ms)`. Parallel CPU work needs Workers or worker_threads.
- Modules: write ESM (`"type": "module"`, `import`/`export`). Node ESM needs file extensions in relative imports (`./util.js`, or `./util.ts` under type stripping); `import.meta.dirname` replaces `__dirname`. `require(esm)` works in Node 22.12+/24 unless the module graph uses top-level await (ERR_REQUIRE_ASYNC_MODULE). Node 26 needs `.cjs`/`.mjs` for extensionless files in type:module packages. Define a package's public entry points with an `exports` map.
- Node runs .ts by stripping types: no type checking, tsconfig ignored, and `enum`, runtime `namespace`, parameter properties and import aliases fail with ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX. Enable `erasableSyntaxOnly` and `verbatimModuleSyntax`, use `import type`, and run `tsc --noEmit` separately. `--experimental-transform-types` was removed in Node 26.
- TypeScript: enable `strict` (the default in TS 7), `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`. Prefer `unknown` to `any`, unions of string literals and `as const` objects to `enum`, discriminated unions with a `never` exhaustiveness check, `satisfies` to check without widening, and type guards (`v is T`). Types vanish at runtime, so validate external data (JSON, requests) with a schema library such as Zod or Valibot.
- TS 7 removed `target: es5`, `downlevelIteration`, `moduleResolution: node/node10/classic`, AMD/UMD/System modules, `baseUrl` (make `paths` relative), and `esModuleInterop: false`. `types` now defaults to [], so add `"types": ["node"]`. TS 7.0 has no compiler API: typescript-eslint and Vue/Svelte/Astro tooling still need TS 6 through `@typescript/typescript6` (npm alias) until 7.1.
- Modern APIs worth using: iterator helpers, Set union/intersection, `Promise.try`, `Object.groupBy`, `Array.fromAsync`, `Error.isError`, `Math.sumPrecise`, Uint8Array `toBase64`/`fromHex`, `Map.getOrInsertComputed`, `RegExp.escape`, JSON imports `with { type: "json" }`.
- Runtimes: Node (npm/pnpm, `node --test`, `--watch`, `--env-file`); Deno (deny-by-default `--allow-*` permissions, `deno check`, `npm:`/`jsr:` specifiers); Bun (`bun install`, `bun test`, built-in TS transpile without type checking). Prefer web-standard APIs (fetch, URL, Web Streams) for portable code.
- Tooling: Vite, Vitest or the built-in test runners, Playwright for end-to-end tests, ESLint flat config or Biome/oxlint, Prettier. Commit the lockfile and run `npm ci` in CI.
- Security: never pass untrusted strings to innerHTML, eval, new Function or setTimeout(string); use textContent, DOMPurify, CSP and Trusted Types. Block prototype pollution (`__proto__` keys; use Map or `Object.create(null)`). Use parameterized SQL and execFile/spawn with argument arrays. Avoid regexes that backtrack on user input. Use `crypto.getRandomValues`, never Math.random, for tokens. Anything in client bundles is public.
- Performance: keep object shapes stable (initialize all fields in the constructor), avoid per-frame allocations, use typed arrays for numeric buffers, batch DOM reads and writes, and use requestAnimationFrame with a fixed-timestep accumulator.
- Game dev: Phaser, PixiJS, Three.js (WebGPU renderer), Babylon.js, PlayCanvas; Rapier physics (WASM); Colyseus or ws for authoritative servers; roblox-ts compiles TS to Luau.
- From Luau: `..` becomes `+` or a template literal with `${}`; `~=` becomes `!==`; `nil` becomes undefined/null; `pairs` becomes `for (const [k, v] of map)` or `Object.entries`; `pcall` becomes try/catch; `task.wait(s)` becomes `await new Promise(r => setTimeout(r, s * 1000))`; `a // b` becomes `Math.floor(a / b)`.
