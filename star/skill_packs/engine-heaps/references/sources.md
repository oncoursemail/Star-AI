# Sources for engine-heaps

Official documentation reviewed 2026-10-13 (accessed by web, not by a live engine run):

- https://github.com/HeapsIO/heaps/releases (2.1.1 on 2025-06-07 is the latest release; 2.0 and 2.1 notes)
- https://raw.githubusercontent.com/HeapsIO/heaps/master/CHANGELOG.md (2.0 Vector/Vector4 and buffer unification; 1.5 renames; dt in seconds)
- https://raw.githubusercontent.com/HeapsIO/heaps/master/hxd/App.hx (init, update, s2d, s3d, setScene)
- https://heaps.io/documentation/hello-world.html (minimal app and JS hxml)
- https://heaps.io/documentation/hello-hashlink.html (hlsdl, hldx, dx12, hl run)
- https://heaps.io/documentation/resource-management.html (hxd.Res init functions, resourcesPath, live update)
- https://heaps.io/documentation/installation.html (haxelib install and HashLink libraries)
- https://haxe.org/download/ (Haxe 4.3.7 stable, Haxe 5 preview)
- https://github.com/HeapsIO/hide (Hide editor)

These are documentation references; no editor/compiler run is claimed for the skeleton.
