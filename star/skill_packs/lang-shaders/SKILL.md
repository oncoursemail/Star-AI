# Shader languages (HLSL, GLSL, WGSL, Slang)
- Roblox has no user shader language: never offer HLSL, GLSL or WGSL code for a Roblox experience. Use ParticleEmitter, Beam, Trail, SurfaceAppearance, Highlight and post-processing instances (Bloom, ColorCorrection, DepthOfField, SunRays) instead.
- Pick the language by target: D3D12 and Unreal and Unity use HLSL (DXC to DXIL, or DXC -spirv for Vulkan); OpenGL, WebGL 2 and Godot compute use GLSL (glslang or glslc to SPIR-V for Vulkan); WebGPU, wgpu and Bevy use WGSL; Slang is an HLSL superset with modules, generics and autodiff that emits SPIR-V, DXIL, Metal, WGSL, GLSL and CUDA. Current: HLSL Shader Model 6.9 retail (Feb 2026), GLSL 4.60 and GLSL ES 3.20, WGSL W3C Candidate Recommendation, Slang language version 2026.
- Shaders run in parallel lanes with no heap, no recursion, no strings and no runtime errors: bad math yields NaN or garbage silently. Guard with max(x, 1e-6) before division or normalize, pow(max(x, 0), p), and clamp before acos.
- Matrices: GLSL and WGSL are column-major and `M * v` transforms a column vector; `m[i]` is a column. HLSL default packing is column_major, `M[i]` is a row, `mul(M, v)` is column-vector style and `mul(v, M)` row-vector style. A transposed or wrongly rotated object almost always means the CPU upload convention and the multiply order disagree: fix one convention, do not sprinkle transpose calls.
- Buffer layout: a vec3/float3 has size 12 but alignment 16. std140 (GLSL uniform blocks) and the WGSL uniform address space round array strides to 16 bytes, so float[4] takes 64 bytes; HLSL cbuffer elements may not straddle a 16-byte boundary and each array element starts a new 16-byte register. Prefer vec4 fields or explicit padding, and mirror the layout on the CPU side.
- Bindings: HLSL register(t0, space1), GLSL layout(set = 1, binding = 0), WGSL @group(1) @binding(0) must match the root signature, descriptor set layout or bind group layout exactly, including resource type. In WebGPU, layout auto drops unused bindings. Use reflection (DXC, SPIRV-Reflect, slangc -reflection-json) rather than guessing.
- Uniformity: implicit-derivative sampling (HLSL Sample, GLSL texture, WGSL textureSample) and dpdx/ddx/fwidth are undefined in non-uniform control flow; WGSL rejects it at compile time with "must only be called from uniform control flow". Fix by sampling before the branch or using explicit level or gradient (SampleLevel, textureLod, textureSampleLevel). Lowering the derivative_uniformity diagnostic is a last resort.
- Barriers (GroupMemoryBarrierWithGroupSync, barrier, workgroupBarrier) must be reached by every invocation of the workgroup: never place them inside a branch on thread id or after an early return. Pad with a bounds-checked value instead of returning early.
- GLSL ES (WebGL 2, mobile): the fragment stage needs `precision highp float;` (or mediump); there is no implicit int to float conversion, so write 1.0 not 1. Validate every GLSL file with glslang in CI because desktop drivers accept non-standard code.
- WGSL: no implicit conversions (use f32(i), 1u, 2.0), let is immutable and var mutable, select(falseValue, trueValue, cond) argument order, float % truncates (floored mod is x - y * floor(x / y)), default limit 256 invocations per workgroup, enable f16 needs the shader-f16 device feature. Read errors with getCompilationInfo and pushErrorScope or popErrorScope; host calls like mapAsync are async.
- HLSL: compile with DXC (-T ps_6_6 -HV 2021 -WX). HLSL 2021 forbids vector && and || and ?: elementwise; use and(), or(), select(). half is 32-bit unless -enable-16bit-types. Wrap per-lane bindless indices in NonUniformResourceIndex. Enable the D3D12 debug layer, GPU-based validation and DRED to diagnose device removed (TDR).
- Slang: since language 2025 declarations default to internal and each module needs `module name;`; mark cross-module API public. Language 2026 makes (a, b) a tuple, requires dyn for dynamic dispatch and removes struct inheritance. Pin the slangc version in CI because weekly releases can break code.
- Debug with RenderDoc, PIX, Nsight or the WebGPU Inspector; there is no printf in WGSL, so write debug values to a storage buffer. Test compute shaders by dispatching known inputs, reading back and comparing with a CPU reference within a tolerance, never with exact float equality.
- Luau mapping: Vector3 is vec3/float3/vec3f, CFrame is a 4x4 matrix, math.clamp is clamp or saturate, Lerp is lerp (HLSL) or mix (GLSL, WGSL), arrays are 0-based and fixed-size, and there are no tables, nil or coroutines.
