# Python (3.13 to 3.15)
- Versions (checked 2026-10-13): 3.15.0 released 2026-10-09; 3.14 is the safe default target; 3.13 gets security fixes only. Say which features need 3.14 or 3.15.
- Indexing is 0-based; `range(a, b)` excludes b; `xs[-1]` is the last item. Falsy: None, False, 0, 0.0, "", and every empty container (Luau: only nil and false). Compare to None with `is None`.
- Names are references: assignment never copies. Never use a mutable default (`def f(x=[])`); use None or `field(default_factory=list)`. Assigning inside a function makes the name local (UnboundLocalError); use `nonlocal`/`global`.
- `list.sort()` returns None; `sorted(x)` returns a new list. `d[k]` raises KeyError; use `d.get(k)`, `in`, or `defaultdict`. Do not mutate a dict or list while iterating over it.
- Typing: annotations are never enforced at runtime; mypy, pyright or ty check them. Write `X | None`, `list[int]`, PEP 695 generics `def first[T](xs: Sequence[T]) -> T | None`, `type Alias = ...`, `Protocol`, `TypedDict`, `@override`, `TypeIs`. 3.14 defers annotation evaluation (PEP 649): forward references need no quotes; read them with `annotationlib.get_annotations`.
- t-strings (3.14, PEP 750): `t"..."` gives a `string.templatelib.Template`, not a str. Only pass it to code that processes Templates.
- 3.15 adds `lazy import x` (module scope only; errors appear at first use), `frozendict`, `sentinel`, `*` unpacking in comprehensions, and UTF-8 as the default encoding. Before 3.15, always pass `encoding="utf-8"` to `open()` (Windows defaults to cp1252).
- asyncio: `asyncio.run(main())` once; structure work with `async with asyncio.TaskGroup()` and `asyncio.timeout()`; never `time.sleep` or blocking I/O inside async code (use `await asyncio.sleep`, `asyncio.to_thread`). Keep references to created tasks. A coroutine that is never awaited does nothing ("coroutine was never awaited").
- GIL: threads help I/O, not CPU work. For CPU work use processes, `concurrent.interpreters` (3.14), or the free-threaded build `python3.14t` (officially supported, not the default; slower single-threaded; a non-ready C extension re-enables the GIL). Shared state still needs locks.
- Guard entry code with `if __name__ == "__main__":` (required for multiprocessing on Windows/macOS, and on Linux since 3.14 defaults to forkserver).
- Tooling: uv (`uv init`, `uv add`, `uv run`, `uv lock`, `uv python install 3.14`), `pyproject.toml` with `[project]` and `[dependency-groups]`, Ruff for lint and format, pytest for tests (`parametrize`, fixtures, `tmp_path`, `pytest.raises(match=)`). Run `python -m pip` with the same interpreter that runs the code; ModuleNotFoundError usually means the wrong venv. On Windows install Python with the install manager (`py install 3.14`).
- Idioms: dataclasses (`slots=True`, `frozen=True`), `pathlib.Path`, `with` for every resource, `enumerate`/`zip(strict=True)`, comprehensions, `match` statements, `StrEnum`, f-strings (`f"{x=}"`), `"".join` for string building, logging rather than print in libraries.
- Errors: raise specific exceptions (`ValueError`, `KeyError`), catch narrowly, never a bare `except:`. Use `except*` for ExceptionGroup from TaskGroup. 3.14 warns on return/break/continue inside `finally`.
- Performance: profile first (cProfile, py-spy; 3.15 `profiling.sampling`). Use sets and dicts for membership, deque for queues, NumPy for numeric loops, `__slots__` for many small objects. The JIT is experimental and off by default; promise no speedup from it.
- Security: never eval/exec, pickle, marshal or `yaml.load` untrusted data (`json`, `yaml.safe_load`). Run subprocess with an argument list, not `shell=True` with interpolated strings. Use parameterized SQL (`?` placeholders). Use `secrets` (not `random`) for tokens and `hmac.compare_digest`. Set `timeout=` on every HTTP call. Use tarfile `filter="data"`. Check user paths with `resolve().is_relative_to(base)`.
- Game dev: pygame-ce (not old pygame) with a fixed-timestep loop, Arcade, Pyglet, Panda3D/Ursina, Ren'Py; Blender `bpy` scripts for asset pipelines.
- From Luau: `..` becomes `+`/f-string; `~=` becomes `!=`; `a:m()` becomes `a.m()` with explicit `self` in the def; `pcall` becomes try/except; `task.wait` becomes `await asyncio.sleep`; `#t` becomes `len(t)`; `//` is floor division in both.
