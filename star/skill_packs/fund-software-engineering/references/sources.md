# Sources for fund-software-engineering

Distilled from the long-form research note `docs/research/fundamentals/software-engineering.md` (researched 2026-10-13; a copy ships as `references/notes.md` so Agent mode can read it with star_skill_reference). Primary sources (papers, official documentation, talks by the engineers who shipped the technique, standards bodies) come first; secondary write-ups are marked as such. This pack is engine- and language-independent: it names no engine API, so there is nothing to verify with the knowledge service /api-lookup.
