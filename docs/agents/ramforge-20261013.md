### Verdict
- **A1 beats baseline beyond noise**: +6.4% (bench) and +6.6% (server), same prompt speed and first token, identical
  greedy text. It is below the 10% bar first set for deployment, so it ships **opt-in** only (PR below).
- BARRIER: no gain, do not use. BLOCK alone: half the gain.
- Background node for the planner (msg #218/#219): **do not pin heavy jobs to node 3 while the model spans 4 nodes
  (-71%)**. The 3-node layout (N3P) makes it work (heavy job on node 3 costs the model 1.7%) but costs 3% generation
  and 9% prompt speed in server runs vs today, and needs models.ini thread changes (-t 18 -tb 36). Use it only if
  brain 1 must run heavy CPU jobs during chat; otherwise keep background unpinned/low priority or on brain 2.
