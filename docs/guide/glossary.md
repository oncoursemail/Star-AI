# Glossary

Plain-language meanings of the words used in STAR and this guide.

**Agent mode** – A way of working where STAR plans steps, uses the tools you allowed, and checks its work.
Slower than Fast or Auto. See [Chatting](chatting.md#fast-auto-or-agent).

**API key / key** – A secret code that lets one program use another service (for example a STAR Server, a
search service or Roblox). Treat it like a password. STAR keeps keys in Windows Credential Manager.

**Auto mode** – STAR decides how to handle each message. The starting mode.

**Brain** – The AI model that writes STAR's answers. It can run on your PC ("the brain on this PC" or "STAR
Brain"), on a [STAR Server](star-server.md), or with a cloud provider you choose.

**Checked example** – A worked practice answer that passed STAR's automated Luau checks. Not the same as being
tested in Roblox Studio.

**Cloud provider** – An AI company's online service (GroqCloud, OpenRouter, Gemini or Cerebras). Only used if you
select one and add your own key.

**ComfyUI** – A separate free program that makes pictures on your PC. STAR uses it for **Create image**.

**Context** – How much of the conversation the brain can keep in mind at once. Very long chats can run out of it.

**Correction** – What you tell STAR after clicking **Not helpful**: what was wrong and what is right. See
[Self-learning](self-learning.md#correct-an-answer).

**Credential Manager** – The safe place in Windows where passwords and keys are stored.

**`%APPDATA%\STAR`** – The folder where STAR keeps your chats, settings, lessons and the downloaded brain. Paste
it into the File Explorer address bar to open it.

**DESIGN.md** – A short text file describing a project's colours, fonts and layout rules. See
[Design tools](design-tools.md#designmd-design-notes).

**Discord bot** – STAR's own account on Discord that answers only you. See [Discord](discord-bot.md).

**Fast mode** – Quick answers without tools.

**FFmpeg** – A free program that reads video and audio files. STAR needs it to understand videos.

**GPU / graphics card** – The part of your PC that makes graphics. AI models run much faster on it.

**Lesson** – A short written note STAR uses in later answers for the same project, such as a preference or a
correction. You can approve, edit, stop using or delete each one.

**Luau** – The programming language used for Roblox games.

**Luau check** – STAR checking Luau code for mistakes before showing it (it compiles and type-checks; it does not
run the code).

**Map plan** – A written layout for a Roblox map that STAR checks on paper (overlaps, jumps, spawn room) before
anything is built.

**MCP** – A standard way for AI programs to connect to other apps. Roblox Studio and Blender connect to STAR this
way.

**Night school** – STAR practising Roblox tasks on a STAR Server while nobody is using it, and keeping lessons that
prove they help. See [Self-learning](self-learning.md#night-school).

**Open Cloud** – Roblox's official online service for programs. STAR can use it, with your approval, to test or
save versions of a private test experience.

**Opt-in** – A feature that is off or not set up until you choose to turn it on.

**Private network address** – The number a device has on your home network (often starting with `192.168.`,
`10.` or `172.`). Not reachable from the internet.

**Project** – A group of chats, lessons and references in STAR. Lessons from one project are never used in another.

**Sandbox / test place** – A blank, unsaved Roblox place used only for trying things. The only kind of place STAR
will edit.

**STAR Server** – Another computer on your home network that runs the brain for STAR. See
[STAR Server](star-server.md).

**Studio** – Roblox Studio, the program used to build Roblox games.

**Token** – A secret code, like a password, for example the one that lets the Discord bot log in.

**Visual references** – Pictures you pin to a project so STAR keeps your style in mind.

**Web search** – STAR looking things up on the internet through a search service you set up. See
[Search the web](chatting.md#search-the-web).
