## 2. Research: what makes the good chat apps feel easy (principles, not looks)

Sources: OpenAI help ("Search can match words in a chat's title or messages"; Ctrl+K opens search), third-party
walkthroughs of ChatGPT's sidebar (hover a chat → "More options" → Rename / Delete), the ChatGPT Windows app notes
(companion window, upload files, generate an image from the same box), Claude's single + for context, Emil Kowalski's
design-engineering skill (installed under `.claude/skills/emil-design-eng`), the Vercel web interface guidelines
(`.claude/commands/web-interface-guidelines.md`) and the previous STAR direction docs.

1. **The conversation list is the sidebar.** ChatGPT and Claude put New chat and Search on top and then only chats.
   Everything else is one quiet line or lives in a menu. → STAR keeps Projects and Tools (Roblox Studio is STAR's
   signature), folds Library, Analytics, Brain and Model under **More**, remembers the fold.
2. **Per-chat actions live on the row, revealed on hover/focus.** Rename edits in place; delete is fast and forgiving.
   → "…" on each row (always visible on touch screens): Rename (Enter saves, Escape cancels, double-click also renames)
   and Delete. Delete hides the chat at once and shows **Undo** for 6 seconds; only then is `deleteChat` sent.
   Deleting the open chat drops you into a fresh one immediately, like ChatGPT.
3. **One box, one +.** Attach, create an image and other capabilities are entries in the + menu, and what is on shows
   as a removable chip. The menu opens short: *Add photos and files, Look at my screen, Create image, Search the web*;
   *Transcribe audio, Use a team, Read STAR source* sit behind **More** inside the menu.
4. **The model/mode picker is one small pill** that opens a list with a sentence per choice (ChatGPT's model picker,
   Claude's style menu) instead of three always-visible buttons.
5. **Show, don't decorate, while working.** A shimmer on the real phase word (no fake steps); an image request
   shows a frame of the chosen shape where the picture will land.
6. **Screen sharing is explicit.** Assistants that look at your screen ask each time and make the shared picture
   visible before sending. → A consent dialog, one screenshot, shown as a thumbnail chip you can remove.
7. **Motion only where it explains** (Emil): strong ease-out `cubic-bezier(0.23, 1, 0.32, 1)` for UI, under 300 ms,
   `scale(0.97)` on press, popovers grow from their trigger, crossfades masked with a 2 px blur, springs only for the
   decorative lean, no animation on keyboard-repeated actions, everything off under reduced motion.

## 3. Decisions (each with its reason)

| Decision | Why |
|---|---|
| Sidebar: New chat, Search, Projects, Tools, More (folded), then chats grouped Today / Yesterday / Previous 7 days / Older | First-time users see chats, not a control panel; nothing was removed, only folded |
| Chat row "…" menu with Rename/Delete, Undo toast instead of a confirm dialog | A confirm dialog interrupts every delete; Undo is just as safe and faster. Nothing leaves the disk until the window passes |
| Top bar keeps search; Rename / Copy conversation / Delete move into one "…" menu; double-click the title to rename | One icon instead of three, same reach |
| Studio chip shows only when the message mentions Studio, Roblox, Luau, place, workspace or playtest, and Studio is not connected yet | The shortcut appears when it is useful and disappears otherwise |
| Mode pill (Fast / Auto / Agent) with descriptions | Same three behaviours, one control; arrow keys still move the choice |
| "Look at my screen": consent dialog → Python `captureScreen` with `consent: true` → STAR hides its window, grabs the screen it is on, saves `screen-captures/screen-YYYYMMDD-HHMMSS.png`, attaches it, shows a thumbnail; nothing is sent until you press Send | The owner wanted "hey, look at my PC"; privacy needs a per-use yes and a visible result. The model has no tool that can reach this |
| Create image stays a + menu entry; the thread shows a placeholder frame (square / wide / tall / draft) while it is made, then the picture inline (existing path) | Image generation lives in the chat, not in a separate area |
| Star in the empty chat (104 px) and in the Thinking row (40 px): breathes, blinks, tilts while thinking, cross-fades between approved faces, leans toward the pointer on a spring in the empty chat only | A welcoming, alive first screen without a constantly animated character over your work; the floating pet stays opt-in |
| Ease token changed to `cubic-bezier(0.23, 1, 0.32, 1)`; press feedback `scale(0.97)` on sidebar items, chips, + and the mode pill | Emil's guidance: snappier start, soft landing; the interface acknowledges presses |
| Page eyebrows removed | Uppercase eyebrows were template chrome |
| Site: labels in the text face, no crop marks, hero kicker and fact pills removed, Connections table removed (it repeated the capability table), the evaluation numbers folded into a disclosure (still on the page, still dated), PR board folded behind "Open work on GitHub" with counts, Star's eight faces in one row that reacts to the pointer, product captures re-taken from the new interface | Less "AI template", shorter page (12,762 → about 10,300 px at 1440), every honesty statement kept |

## 5. Critique passes

**Pass 1** (first render): Star at 84 px melted into the black canvas (added a faint warm pool behind her and went to
104 px); Thinking face at 30 px read as a blob (40 px); a gold focus ring was drawn around menu items opened by mouse
and a double edge around the rename field (menu items now show focus as an inset edge, the rename field keeps its gold
border only); the Undo toast covered the Settings row (moved above it); "Chats" label stacked on top of "Today".

**Pass 2**: the preview `error` fixture never showed its failure row because the scripted turn captured the chat id
before React re-rendered (preview-only bug, fixed); the image placeholder claimed "on this PC" although images can run
on the STAR Brains (now "Your image will appear here"); the site face row was invisible because `display:block`
broke the grid that stacks image and fallback (fixed); the site captures still showed the old interface (re-captured
with `scripts/capture-site-media.mjs`).

## 6. Not done / known limits

  pruning, size and type checks and the UI flow are tested.
- Settings is still one long page; regrouping it into tabs is the next step.
- The floating pet (`StarPet`) is unchanged and still opt-in.
