# STAR Intelligence — Public Downloads

**This repository contains only official desktop installers, checksums, release notes and the public STAR website.**

STAR's main source repository remains private. Model weights, personal conversations, local knowledge, GitHub credentials and development secrets are never uploaded to this public repository.

## Download STAR

Visit **[Releases](../../releases/latest)** for the latest version of `STAR-Setup-vX.Y.Z.exe`.

## Website

Once GitHub Pages is enabled for `main` / root, the website is at:

https://oncoursemail.github.io/Star-Intelligence-Downloads/

## Maintainer setup

The private `oncoursemail/Star-AI` build publishes verified installer assets after Windows tests. Public publication additionally requires a repo-scoped, expiring secret in the private project's Actions configuration, limited to this public repository's **Contents: read and write** permission.

**This repository should not contain STAR Python sources, proprietary assets, API keys, LLM weights, transcripts, or training data.**
